# 棒人間は正直

AIの「本音」が、小さなシルエットの身ぶりに出てしまうチャットアプリです。
[しっぽは正直](https://konbu-love.github.io/shippo-chat/) の派生版です。

- 画面の左:棒人間・犬・花のどれか。AIの本音の気分で動きます
- 画面の右:楷書・縦書きのチャット
- AIの返事はいつも丁寧。でも心の中の住人は正直です

口では丁寧に答えているのに、横で地団駄を踏んでいたら……内心はそういうことです。

## 遊ぶ

https://konbu-love.github.io/bou-chat/

スマホの縦画面向けです。

## 使い方

1. 上のURLを開く
2. 左上の ⚙ を押して、Gemini の APIキーを貼り付けて「保存」
3. 下の入力欄から話しかける
4. ⚙ の「姿」で、棒人間・犬・花を切り替えられます

「しっぽは正直」でキーを入れたことがあれば、同じキーがそのまま使われます。

### APIキーの取り方(無料)

1. [Google AI Studio のキー画面](https://aistudio.google.com/apikey)を開く
2. Googleアカウントでログインする
3. 「APIキーを作成」を押す
4. 出てきた文字列をコピーして、アプリの設定に貼る

## 身ぶりの読み方

| 本音 | 棒人間 | 犬 | 花 |
| --- | --- | --- | --- |
| 平常 | 立っていて、時々体重を移す | 四つ足で立ち、時々テクテク足踏み | まっすぐ咲いて、時々そよぐ |
| うれしい | 両手を上げて跳ねる | 跳ねて、しっぽをぶんぶん振る | 花びらを大きく開いて弾む |
| 驚き | 手足を広げて飛び上がる | 足を突っ張って飛び上がる | 茎が伸びて、花びらが逆立つ |
| イライラ | 腕を組んで地団駄を踏む | 前を低くして吠える | そっぽを向いて葉をバタバタ |
| 興味 | 身を乗り出して首をかしげる | おすわりで耳を立てる | チャットのほうへ傾く |
| しょんぼり | うなだれる | 伏せて頭を地面につける | しおれる |
| くつろぎ | あぐらで揺れる | 伏せてしっぽをゆっくり振る | つぼみに閉じて揺れる |

返事を待っている間は、考え中のポーズになります。

## 注意

- APIキーと会話は、あなたの端末のブラウザの中だけに保存されます。作者には届きません
- Gemini の無料枠では、会話の内容が Google のサービス改善に使われることがあります。人に知られたくないことは書かないでください
- 「支払い設定つきで使えません」と出たら、支払い設定(請求先)のないプロジェクトでキーを作り直してください
- 混み合っていて返事が来ないときは、少し待つか、設定のモデル名を変えてみてください(初期値は `gemini-3.5-flash-lite`)
- 「モデルが見つからない」と出たら、設定のモデル名を新しいものに書き換えてください
